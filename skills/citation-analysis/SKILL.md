# 文献计量与引文网络分析

围绕用户的研究问题构建可审计的语料库和网络，计算适合该语料的数据指标，并说明指标能够与不能支持的结论。默认在当前回答中返回结果，不写本地文件；用户明确要求导出分析产物时，才写入其指定的新路径。不得因调用本 Skill 获得上传文件、写入远程系统、登录账号、购买数据或调用收费服务的权限。

## 工作边界

- 仅分析当前会话真实取得或用户明确提供的数据；不得补造引用数、作者身份、关系边、h-index、期刊指标或研究前沿。
- 需要检索元数据或引用关系时，优先调用已安装的 `academic-literature-search`，使用公开只读来源（如 OpenAlex、Crossref、PubMed、arXiv 或 Semantic Scholar）；这会把最少必要的查询词或公开标识符发送给相应服务。若实际工具不可用，说明缺口，不用猜测代替。
- 不把用户的未发表稿件全文、受限语料、个人信息、机构内部数据或机密项目描述发送给公开接口。需要联网补数时，优先使用 DOI、PMID、arXiv ID 等公开标识符；无法去敏时先停下并说明限制。
- 检索文献、核验来源存在性、核验全文可得性、核验某项主张得到原文支持是不同任务。此 Skill 不把元数据命中当作全文或主张核验。
- 不把引用量、中心性、聚类或期刊级指标解释成论文质量、因果影响或临床有效性。

## 分析流程

1. 明确单位与边界：研究问题、语料范围、数据库、查询式或纳入清单、检索日期、时间窗、文献类型、语言和领域。
2. 定义实体与关系：论文和作者的稳定标识、版本合并规则、去重规则、节点含义、边方向与权重、自引规则、缺失值处理。
3. 选择与问题匹配的方法：描述性产出/引用趋势、作者指标、直接引文网络、共引、文献耦合、合作网络、聚类或领域归一化比较。不要为了“看起来全面”堆叠无关指标。
4. 计算前阅读 [方法与解释边界](references/methods-and-boundaries.md)，只在数据足够、定义明确时计算。
5. 对关键结果做可复核检查：抽查标识与边、报告无法解析的记录、区分数据库总引用数与当前子图入度，并对参数敏感的方法说明参数或稳定性。
6. 回答用户问题，同时报告数据来源、检索时间、语料范围、节点/边定义、去重与版本规则、缺失数据、计算方法和解释边界。

## 输出要求

输出结构随用户问题调整，但必须让别人能够判断结果来自什么数据、如何计算以及可解释到哪里。对排名给出指标定义和并列处理；对网络结果给出节点数、边数和采样边界；对“研究前沿”使用审慎措辞，并将信号与定论分开。数据不足时返回可执行的数据补充建议，不输出伪精确数字。
