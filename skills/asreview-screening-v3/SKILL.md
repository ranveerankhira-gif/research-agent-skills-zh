# 系统综述智能筛选（ASReview 3）

让 ASReview 帮助决定“下一条先看什么”，而不是让模型替研究者决定“哪些研究可以丢掉”。主动学习排序、资格判断、全文排除理由和最终纳入是不同环节。

## 使用模式

- **方案或审计**：检查输入、种子记录、模型用途、停止规则、人工复核和审计记录。读取 [references/screening-safeguards.md](references/screening-safeguards.md)。
- **安装或真实运行**：同时读取 [references/asreview-v3-workflow.md](references/asreview-v3-workflow.md)，先核对当前官方版本和命令，再说明将安装或启动什么、写到哪里和可能耗时。

普通系统综述的协议、检索、去重、人工筛选、提取和 PRISMA 记录由 `literature-review` 负责。本 Skill 只处理 ASReview 主动学习排序及其方法学边界。

## 自动触发后的第一步

本 Skill 只允许通过 `$asreview-screening-v3` 显式调用。先判断用户是在咨询方案、审计现有流程，还是明确要求安装或运行。方案与审计可直接进行只读工作；安装或真实运行前还要读取 [权限与安全边界](references/security-and-permissions.md)。以下动作不能因进入 Skill 而自动执行：

- 安装或升级 Python、ASReview、插件或依赖；
- 启动 `asreview lab` 本地服务或打开浏览器界面；
- 导入用户题录、运行模拟、训练排序模型或写出项目文件；
- 覆盖、重命名或清理原始 RIS、CSV、TSV、Excel 或 `.asreview` 文件。

这些动作需要用户对当前动作的明确授权。若只说“看看怎么做”，交付方案，不执行。

## 运行边界

- 保留原始输入不变，只在用户指定输出目录中创建副本和产物；同名不同内容不得覆盖。
- 默认使用本地模式，不把题名、摘要、标签或项目文件传到外部服务器。
- 不读取浏览器、账号、邮箱、私有文献库或凭据，除非用户明确将其放入任务范围。
- 不把模型优先级、概率、排名或连续若干条无关记录当成最终排除理由。
- 不声称达到某个召回率，除非有适用的已标注数据、验证方法和真实输出支持。
- 若正式方案要求双人独立筛选，ASReview 不能伪装成第二位独立研究者。

## 输出

根据任务提供：输入和标签质量、ASReview 或插件版本、模型与配置、种子记录来源、人工决策责任、预先规定的停止与复核规则、运行日志位置、保留记录数以及局限。

将关键状态标为：

- `已核验`：来自实际文件、配置、日志或成功运行；
- `待执行`：已规划但尚未获授权或运行；
- `材料缺失`：缺少题录字段、标签、协议或审计记录；
- `方法风险`：现有设计可能漏掉相关研究或夸大性能。
