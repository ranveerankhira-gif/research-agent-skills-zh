# 科研论文深读

## 核心原则

以论文原文为唯一内容依据。区分作者报告、论文中引用的外部主张和本次分析者的解释；不能读取的正文、附录、图表或补充材料必须明确标成未核验。

这项 Skill 不建立 Obsidian 仓库、知识图谱或固定目录，不自动下载未提供的全文，不把一次深读升级成跨论文综述，也不默认写入任何文件。

## 开始前

- 确认具体论文及可访问材料。只有 DOI、PMID、arXiv ID 或题名时，先说明当前只有题录；用户同时要求获取全文时，转交 `research-source-acquisition` 定位合法公开全文，不在深读请求中静默下载、登录或绕过访问控制。
- PDF 是主要材料时，检查实际页面、双栏顺序、脚注、图表、公式和附录；不要只依赖抽取文本。
- 论文存在多个版本时，记录正在阅读的版本、日期或来源，不把预印本与正式发表版混为一谈。
- 根据用户问题选择深度；不要强制统一笔记模板或固定评分表。

## 深读要求

1. 先识别研究问题、研究对象、设计、数据、分析方法和主要结论，再判断哪些章节或图表需要细读。
2. 对关键结论记录可复查定位：印刷页码或 PDF 页码、章节、小节、表、图、公式或补充材料编号。若页码体系不一致，应说明采用哪一种。
3. 抽取数值时保留方向、单位、分母、置信区间或不确定性以及比较对象；不得根据图形目测伪造精确数值。
4. 方法评价应围绕实际设计、估计目标、对照、测量、缺失数据、统计假设和外推边界，避免套用与研究类型无关的检查表。
5. 明确区分：作者明确陈述的局限、本次阅读发现的潜在局限、以及仅凭现有材料不能判断的问题。
6. 发现论文引用其他来源来支撑关键事实时，不把二手引用当成已经核验的原始证据。

## 输出

按用户问题组织回答。必要时可使用“结论—原文定位—解释—边界”的证据表，但不要无条件生成固定数量的摘要、评分或标签。

至少应让用户看清：

- 论文真正回答了什么，以及没有回答什么；
- 核心方法和结果分别来自哪里；
- 主要结论需要哪些假设才能成立；
- 哪些判断是原文事实，哪些是分析性解释；
- 仍需核验的全文、附录、数据或引用。

若用户要求保存笔记，先使用用户指定位置；未指定时提出文件名建议，不擅自创建永久知识库。保留原始论文，不覆盖源文件。

## 权限与文件安全

- 只读取用户明确指定的论文、附录和补充材料，不扫描相邻目录、文献库、邮箱或云盘。
- 只有用户要求核对公开版本、勘误、撤稿状态或官方补充材料时才联网；只访问公开合法来源，不登录账号、不使用凭据、不上传本地论文。
- 默认在回复中交付分析。保存笔记时确认目标路径并创建新文件；同名文件存在时停止，不覆盖论文、批注或既有笔记。

## 边界

- 找论文交给学术文献检索能力；多篇证据综合交给文献综述能力。
- 风险偏倚或证据确定性只有在用户明确要求时才进入对应专业框架。
- 不替作者补写缺失结果，不从摘要推断全文细节，不把相关性改写成因果性。
- 不上传未公开论文、审稿稿件或补充材料到外部服务。即使用户提出外传，也应先核对其权限、保密义务和服务的数据处理条件；本 Skill 默认保持本地处理。
