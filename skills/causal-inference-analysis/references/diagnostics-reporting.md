# 因果诊断、敏感性分析与报告

## 诊断回答什么

- 协变量平衡：调整后已测协变量是否更可比；不能回答未测混杂是否消失。
- 重叠与权重：目标人群中是否有足够处理概率支持；极端权重提示外推和方差风险。
- 处理前趋势：可发现某些双重差分问题；不能证明未处理结果将继续平行。
- 第一阶段：工具是否预测处理；不能证明排除限制。
- 阈值密度与协变量连续性：可发现部分 RDD 操纵或共变问题；不是完整有效性证明。
- 安慰剂/负对照：有助发现偏差机制；单次不显著不能证明无偏。

优先展示标准化差异、分布和有效样本量等设计相关诊断，避免只用显著性检验。诊断应与所选估计量、聚类和时间结构一致。

## 敏感性分析

围绕最脆弱的假设选择分析，而不是机械罗列：

- 不同合理协变量集、处理/结果定义和样本边界；
- 权重截断、匹配口径、带宽、窗口、供体池或比较组；
- 未测混杂强度、选择偏差或误分类需要多大才改变结论；
- 缺失数据、删失、干扰和处理版本的替代假设；
- 负对照结果/暴露或伪处理时间（需要领域上合理）。

敏感性分析若同样依赖不可辩护假设，不能当作稳健性证据堆叠。

## 推断

按分配层级、重复测量和政策实施单元处理聚类。样本或聚类数量少时，说明常规渐近标准误的局限并考虑合适的小样本方法。多结局、多时期或多亚组需要预设主次关系或说明多重性；不要只挑显著窗口。

区分统计不确定性与识别不确定性：窄置信区间不意味着因果偏差小。

## 最低报告字段

1. 因果问题、目标人群、处理/比较、结果、时间和估计量；
2. 数据来源、纳入排除、时间零点和变量定义；
3. 因果结构与变量角色；
4. 识别假设及其领域依据；
5. 估计方法、标准误/区间和软件版本；
6. 平衡、重叠、趋势、第一阶段或阈值等方法特定诊断；
7. 主结果的绝对与相对尺度、实际意义和不确定性；
8. 敏感性、异质性、缺失/删失处理和负对照；
9. 不能由数据检验的假设、外推边界和替代解释。

措辞应与证据匹配：如果识别策略不足，使用“相关”“与……一致”或“在以下强假设下估计”，而不是无条件写“导致”。
