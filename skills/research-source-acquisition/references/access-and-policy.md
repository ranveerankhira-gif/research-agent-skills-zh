# 账号、许可与数据使用边界

## 通用原则

账号存在、申请获批、文件下载和允许 Codex读取是四件不同的事。平台条款优先于便利性。Codex可以协助定位、填写非敏感草稿、操作用户已登录的页面和下载验收，但用户本人处理身份、密码、验证码、MFA、法律协议、伦理承诺、机构签署和付款。

公开 Skill 不预设持续授权。只有当前用户在当前任务中明确授权下载后的读取或分析，且当前适用的许可证、数据使用协议和平台规则明确允许对应 AI 处理时，Codex 才能继续。条款含糊或冲突、限制云端/外部/生成式 AI、用户仅授权代下载，或用途超出当前任务时，一律停在文件验收和元数据登记。

## 仅代下载模式

用户明确只授权取得文件时：

1. 使用官方来源和用户已授权会话；
2. 保存到独立目录，不放入当前项目或自动索引/云同步目录；
3. 不打开、解压、预览、抽样读取或分析文件；
4. 只报告文件名、路径、大小、哈希、来源、版本和下载时间；
5. 后续读取或分析必须另行确认，并先检查许可。

## IPUMS

- IPUMS 是多个集合，不要求用户为未知未来研究预先注册全部来源。
- API 的通用门槛：IPUMS 账号、目标集合有效注册、API Key。
- IPUMS USA/CPS 数据免费，官方页面称注册审批即时；仍需用户本人接受许可。
- IPUMS International 免费但属受限制微观数据：要求个人身份、机构、至少 50 词英文研究说明，研究团队成员分别注册；许可有效一年。
- 当未来课题出现时，先根据国家、人群、年份和分析单元选择集合，再协助注册/申请/下载。不要把 API Key 粘贴到聊天中。

官方入口：

- API 要求：https://developer.ipums.org/docs/v2/get-started/
- 微观数据 API 覆盖：https://developer.ipums.org/docs/v2/apiprogram/apis/microdata
- USA 数据说明：https://usa.ipums.org/usa/data.shtml
- International 注册：https://account.ipums.org/ipumsi/user/new

## CFPS

- 公开数据仍需注册并申请下载权限，通过人工审核后下载；普通邮箱可注册。
- CFPS 官方数据平台与北大开放数据平台账号不互通。
- 县、市、地级地理编码等限制数据需通过北京大学中国社会科学调查中心申请，审核可能约三周，并可能仅可在指定地点使用。
- 用户明确授权时，Codex可以协助注册导航、操作已登录页面和下载到隔离目录；这不等于允许读取。
- 使用用户明确指定的隔离目录；不要自行选择盘符，也不要将数据放入 Codex 工作区、云同步或自动索引目录。

CFPS 2026-09-02 AI 政策：

- 禁止 ChatGPT、Claude 等外部生成式 AI、远程 API、浏览器 AI、云端编码 Agent 或企业云 AI 读取/处理家庭级或个人级 CFPS 微观数据，公开和限制数据均适用。
- 可以用 AI 阅读无需注册的技术报告、代码、代码本、问卷和调查元数据；可以让 AI 在不接触微观数据时编写分析代码。
- 可以分享无法识别个人/家庭、且不涉及省级以下地区的汇总统计和模型结果。
- 公开数据可在严格离线或机构认证的本地模型中处理；限制数据使用任何 AI 前需项目组事先批准。

## 受控生物医学/临床来源

UK Biobank、EGA、dbGaP、Vivli、YODA、CSDR、All of Us、Project Data Sphere 等可能要求项目方案、伦理、数据安全计划、机构签署、培训、费用或安全分析环境。只能在具体项目出现时核对当期条件。可以帮助准备研究目的、变量与时间范围、统计分析计划、数据管理计划、安全环境与销毁方案等申请材料，但不得代替研究者作身份声明、伦理承诺或合同签署。

## 外部联系

当数据只能由作者、项目办公室或数据管理员提供时，可以定位联系人并起草请求，说明研究目的、所需变量、时间范围、代码本/处理代码、数据安全和署名安排。发送邮件、提交表单或作出对外承诺仍需用户的新鲜确认；“允许 AI 读取”不等于允许 Codex代表用户联系外部人员。

## 付费与机构数据库

Wind、CSMAR、CEIC、Bloomberg、Refinitiv、WRDS、Compustat、CRSP、Orbis、Statista 等依赖用户或机构的合法订阅。可以在用户已登录且授权的会话中协助导出允许的数据，但不得规避并发、下载量、终端、再分发或自动化限制。
