# 文献综述

帮助完成真正的跨研究证据综合，而不是把若干摘要拼成“综述”。允许自动调用，但触发保持窄范围：用户明确要求系统综述、范围综述、叙述性综述、文献综述章节、可复现检索、纳排筛选、PRISMA 记录、证据提取或跨研究综合时才使用。

不要因快速查一个事实、找一篇论文、核验一个引用、单篇论文解读、普通论文润色或单项统计而自动调用。单条引用和主张核查交给 `literature-evidence-checker`；已有稿件的审阅或改写交给 `paper-review-reviser`；两个以上科研阶段的总协调交给 `research-workflow`；定量合并交给 `meta-analysis`。

## 先确定综述承诺

根据用户目标选择系统综述、范围综述或叙述性综述。三者的适用边界见 [references/review-modes.md](references/review-modes.md)。如果用户只要求制定方案，不要擅自开始联网检索或写入文件。

开始前明确：问题、对象/概念、结局、时间范围、语言、文献类型、纳排标准、所需数据库或来源、截止检索日期和交付形式。缺少但不影响方向的信息可以用醒目的假设继续；会改变检索范围或证据结论的信息先说明缺口。

## 执行原则

1. 先建立协议与检索策略。系统或范围综述按需读取 [references/protocol-and-search.md](references/protocol-and-search.md)。
2. 实际检索时，逐来源记录平台、完整检索式、筛选条件、日期、命中数及分页/游标范围。搜索页面、标题和摘要用于发现与筛选，不等同于全文证据。
3. 去重后仍要区分“记录、报告、研究”。预印本、期刊论文、注册记录、补充报告可能属于同一研究，不能重复计为独立证据。
4. 按预先声明的标准筛选，保留全文排除理由。筛选、提取、质量评价和综合规则见 [references/screening-extraction-synthesis.md](references/screening-extraction-synthesis.md)。
5. 从可访问的原始来源提取研究特征、方法、结果和局限；只看摘要或二手综述时明确降级证据状态。
6. 按主题、机制、设计或结局跨研究综合，呈现一致性、冲突、异质性和证据缺口。不要逐篇摘要堆叠，也不要把“没有找到”写成“不存在”。

## 证据与可复现性门禁

- 不把检索引擎排名、引用量或期刊名气当作纳排标准或研究质量结论。
- DOI 能解析只证明标识符存在；还要核对作者、标题、年份、版本、撤稿/更正状态以及被引用主张是否得到支持。
- 没有实际执行并记录足够覆盖的检索时，不称“系统检索完成”或“已穷尽文献”。明确写成探索性检索或覆盖不完整。
- 不模拟两个“独立审稿人”。若只有一个执行者，记录为单人筛选/提取限制；需要出版级双人机制时要求真实的第二位独立评审者。
- 不静默补造全文、样本量、效应值、排除理由、检索命中数或 PRISMA 数字。无法取得全文的报告标记为“未获取”，不能假装已评价。
- 不用一个通用分数替代适合研究设计的风险偏倚工具，也不把报告质量等同于内在偏倚风险。
- 不因结果方向决定是否纳入；预印本、会议摘要和灰色文献的处理须在协议中预先说明。
- 联网检索只发送完成检索所需的查询词和公开标识符；不把未发表稿件全文、个人信息、受限语料、机构内部数据或机密项目描述发送给公共数据库。
- 不自动登录数据库、绕过收费墙、使用账号/API 密钥、调用收费服务、上传材料或生成收费图片。需要这些动作时先向用户说明并等待授权。

## 交付与状态标记

根据任务规模交付最小充分组合：问题与协议、来源和检索日志、去重与筛选台账、研究—报告映射、纳入研究表、全文排除理由、质量/偏倚评价、证据综合、局限及更新截止日期。

对关键材料使用明确状态：

- `已核验`：已查看足以支持当前主张的原始来源或全文位置；
- `待核验`：仅有题录、摘要、片段或二手转述；
- `材料缺失`：需要但未取得全文、附件、数据或审查记录。

若转入定量合并，先输出独立研究层级的效应量表、方差/标准误、尺度、方向和研究—报告映射，再交给 `meta-analysis`；不能把多份报告误当成多项研究。
