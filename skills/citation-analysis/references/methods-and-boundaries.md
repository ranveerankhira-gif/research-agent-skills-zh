# 方法与解释边界

仅在实际任务涉及相应方法时读取对应部分。所有计算都应保留数据来源、检索日期、语料边界和标识映射，以便复核。

## 1. 标识、去重与作者消歧

- 论文优先使用 DOI、PMID、OpenAlex Work ID、Semantic Scholar Paper ID 或 arXiv ID 等稳定标识。标题、作者和年份只能辅助匹配；合并预印本、会议版和期刊版时必须声明规则。
- 作者指标与合作网络优先使用 ORCID、OpenAlex Author ID 等稳定作者标识，并结合机构、共同作者、主题和时间信息核查。不允许仅按姓名字符串合并同名作者，也不应把姓名变体自动拆成不同作者而不报告。
- 自引过滤需要先定义作者重叠的判据并基于作者身份映射执行。姓名字符串相同或不同都不足以可靠判定自引。

## 2. 引用指标

- h-index、g-index、i10-index 等取决于数据库覆盖、作者归属、版本合并、文献类型和检索日期。报告数值时同时报告这些条件；不同数据库的值不可直接混用。
- “最被引”必须区分来源数据库提供的总引用数与当前采样网络中的入度。前者受数据库覆盖影响，后者只代表子图内部关系。
- 引用速度须说明分母和观测窗口。对刚发表文献、部分年份或短时间窗避免用简单年均值制造伪精确比较。
- 跨年份或跨领域比较优先使用来源明确、方法公开的领域归一化指标，并报告其领域分类、基准集和局限；不能自行把原始引用数贴上“领域归一化”标签。
- 引用量和派生排名不是研究质量、可重复性、真实影响或因果效应的直接度量。

## 3. 期刊级指标

- Journal Impact Factor 是 Clarivate 的特定授权指标。除非数据明确来自其正式来源且许可允许，不得把自行计算的两年引用率称为官方 JIF。
- CiteScore、SJR、SNIP 和 h5-index 也有各自的数据源与口径。只有取得对应来源和版本时才能使用正式名称；否则应按实际公式描述为本地计算指标。
- 不用期刊级指标替代单篇论文评价，也不把数据库收录或高指标等同于出版诚信。

## 4. 网络定义

- 直接引文网络通常为有向图，边方向必须明确为“引用者 → 被引者”或其反向，且全程一致。
- 共引：两篇文献被后续文献共同引用；常用于观察知识基础，结果依赖施引文献集合和时间窗。
- 文献耦合：两篇文献共享参考文献；通常在发表时即可计算，更接近当时研究取向。不得把共引与耦合混称。
- 合作网络通常以经消歧的作者为节点、共同署名为边。边权可为共同论文数或分数计数，必须说明；超大团队论文可能主导网络，需要考虑全计数与分数计数的敏感性。
- PageRank、介数中心性、度中心性、社群和所谓“桥接论文”只解释已构建的采样网络。不得外推成整个领域的影响力、原创性或不可替代性。

## 5. 聚类与研究前沿

- 声称“研究前沿”前，至少说明语料库、数据库覆盖、时间窗、节点与边、最低频次阈值、相似度或归一化方式、聚类算法及参数、标签生成方式。
- 突然增加的引用量是候选信号，不是研究前沿的充分条件；也可能来自数据库更新、争议、撤稿、综述聚合或异常引用。
- 共引聚类更偏向已积累的知识结构，文献耦合和近期文本/关键词信号更适合观察新近活动。选择应与问题和时间滞后相匹配。
- 在可行时改变时间窗、阈值或聚类分辨率做稳定性检查。只在多个合理设定下仍稳定时使用较强表述，否则写成“候选主题”或“近期增长信号”。

## 6. 最低报告清单

最终结果至少披露：

1. 数据库/接口及检索日期；
2. 查询式、种子文献或纳入排除范围；
3. 去重、版本合并、作者消歧和自引规则；
4. 节点、边、方向、权重和分析时间窗；
5. 样本量、缺失/无法解析记录及覆盖偏差；
6. 指标公式或软件/算法、关键参数和并列处理；
7. 结果只适用于何种语料，以及不能支持哪些结论。
