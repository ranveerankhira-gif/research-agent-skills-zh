# 权限与安全边界

## 方案与审计

只读取用户明确提供的协议、题录、标签、配置或日志；默认不写文件、不安装软件、不联网查询包版本。若需要核对当前官方版本，先说明会访问 ASReview 官方文档、GitHub 或 PyPI。

## 安装

安装或升级需要当次明确授权，并在执行前列出目标目录、Python 与 ASReview 版本、包来源、插件、预计下载量和环境变更。使用隔离环境，不写入全局 Python、不覆盖现有目录、不自动升级工作中的环境，也不安装未请求的插件。

## 真实运行

导入题录、创建 `.asreview` 项目、训练或模拟、写导出文件、启动本地服务和打开浏览器都属于独立动作。用户授权“安装”不等于授权导入真实数据或训练；授权“运行”也不等于授权覆盖文件、上传数据或修改原始标签。

本地服务启动后报告绑定地址、端口和进程；优先仅绑定回环地址。任务结束时按用户要求正常关闭，不遗留未知后台进程。题名、摘要、标签和项目文件默认不上传公共服务器。

## 资源与停止条件

运行前说明记录规模、预计耗时、CPU/内存/磁盘需求和输出目录。出现版本不兼容、插件来源不明、端口暴露、输出碰撞、输入许可不明或资源明显超出预估时停止，不擅自升级、换插件或扩大计算。
