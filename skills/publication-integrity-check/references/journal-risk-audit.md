# 期刊身份、收录与投稿风险核验

## 分开回答四个问题

1. **身份**：正式刊名、别名、ISSN/eISSN、出版方、官网和所有权是否对应。
2. **当前收录**：在用户关心的数据库中是否有当前记录，覆盖范围、起止年份和状态是什么。
3. **费用与流程**：APC、其他费用、减免、退款、审稿和版权政策是否公开且一致。
4. **适配与质量**：范围是否适合稿件、编辑和同行评议信息是否可核验；这不能仅由影响因子或“是否 OA”决定。

## 优先来源

- 期刊和出版商官方页面；
- ISSN Portal 或国家图书馆目录；
- DOAJ 的期刊记录与开放获取信息；
- NLM Catalog、MEDLINE 等领域目录；
- Clarivate Master Journal List、Scopus Sources 等官方收录目录；
- COPE、OASPA 或学协会官方成员目录，若与任务相关。

数据库记录会变化。必须记录查询日期、数据库名称、期刊标识、覆盖年份和页面状态。无法访问需要登录的目录时标记 `待核验`，不得用搜索引擎片段冒充官方当前收录。

## 风险信号

下列项目是调查线索，不是单项定罪标准：刊名或域名仿冒；ISSN 与刊名不匹配；出版方身份无法核实；虚构或无法联系的编辑；保证录用或极短审稿承诺；费用在投稿后才披露；索引、影响因子或协会成员资格声称与官方目录冲突；同行评议、撤稿、版权和数据政策互相矛盾。

不要把开放获取、低影响因子、新创刊、地区性出版或未进入某个商业索引本身当作“掠夺性”。历史黑名单、博客和论坛只能提供线索；不要将 Beall's List 或任何单一名单作为最终证据。

## 输出建议

分别给出：

- 已确认的身份和当前索引事实；
- 费用及政策的原文位置；
- 需要进一步核实的风险信号；
- 与稿件主题、类型或地区要求有关的适配问题；
- `可继续评估 / 需要补证 / 高风险暂缓` 的行动建议及理由。

“高风险暂缓”表示证据不足以安全投稿，不是法律或伦理裁决。若用户需要最终确认，可建议联系本机构图书馆、科研诚信办公室或目标数据库。
