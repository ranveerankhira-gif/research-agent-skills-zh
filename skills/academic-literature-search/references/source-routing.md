# 数据源路由

## Crossref

- 适合：DOI 解析、期刊论文题录、出版商、ISSN、基金信息、Crossref 收录的参考文献字段。
- 不适合：全文、完整引用网络、研究质量评价。
- 注意：`is-referenced-by-count` 仅表示 Crossref 当前覆盖内的被引计数。

## PubMed

- 适合：生物医学和生命科学、PMID、MeSH、出版类型和字段化检索。
- 不适合：所有学科的完整覆盖；PubMed 题录不保证可获得全文。
- 查询复杂主题时，同时考虑 MeSH 和题名/摘要自由词，并保存完整检索式。

## arXiv

- 适合：物理、数学、计算机、统计、定量生物等领域的预印本发现和版本化 arXiv 标识符。
- 不适合：把预印本状态解释为同行评议通过。
- 记录实际读取的版本；最新版 URL 与固定版本 URL 的证据含义不同。

## OpenAlex

- 适合：跨学科发现、作者/机构/来源/主题过滤、开放获取信息和引用关系探索。
- 不适合：把自动消歧后的作者或机构身份当作无需核对的事实。
- 被引计数和开放获取字段按查询日期记录。

## Semantic Scholar

- 适合：相关论文、引用和参考文献网络、作者及影响力字段的探索。
- 不适合：用算法推荐代替可复现检索，或用 influential citation 等标签代替人工质量判断。
- 公共无密钥访问可能限流；失败时不反复请求，也不擅自申请或读取 API 密钥。

## 多来源原则

一个来源足以回答精确标识符或简单题录问题时，不为“显得全面”强制查询全部来源。用户明确要求全面检索或综述时，由 `literature-review` 确定数据库组合；不同来源结果以 DOI、PMID、arXiv ID、标题和版本关系保守去重。
