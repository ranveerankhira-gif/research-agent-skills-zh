# 权限、安全与成本边界

## 权限分层

- **公开发现**：查询公开网页或 API，只发送最少必要的公开标识符或去敏检索词。
- **文件下载**：需要明确目标、预计大小、保存目录和覆盖策略；只下载任务所需文件。
- **账号协作**：用户本人处理密码、验证码、MFA、身份和协议；不得读取、导出或记录凭据、Cookie 或认证头。
- **申请与外部联系**：起草不等于提交；提交申请、联系作者或管理员、接受协议和代表用户作出承诺都需要当次确认。
- **付费**：显示价格、币种、计费方式和预计总额后停止；不得自行购买、启用付费 API 或增加收费后备。

## 本地写入

只写入用户为当前任务确认的目标目录。下载使用本流程创建的随机临时文件，验收后再原子移动；同名同内容可复用，同名不同内容生成新名称，不静默覆盖。不得把受限数据、凭据或下载状态写进 Skill 目录。

## 停止条件

遇到登录、验证码、许可含糊、伦理或机构签署、访问控制、付款、上传、对外提交或无法确认 AI 处理权限时停止。网络错误最多按获取协议重试一次；不得通过高频重试、镜像或浏览器自动化绕过限制。

## 成本披露

大文件、商业数据库、机构订阅和按量 API 可能消耗带宽、存储、配额或费用。执行前说明预计规模与收费边界；无法估计时先取得清单，不直接批量下载。
