# 输入契约

## 必需字段

- `study_id`：非空且唯一的研究标识。重复 ID 会被拒绝，因为同一研究的多个效应量通常相关。
- `yi`：分析尺度上的效应量，必须是有限数值。
- `vi` 或 `sei`：抽样方差或标准误，必须为有限正数。如果两列同时存在，脚本会核对 `vi` 与 `sei²` 是否一致，不一致即拒绝。

未知列会保留在原 CSV 中但不参与计算。空行、缺失字段、无穷值和非法数值不会被静默删除，而是直接报错并指出行号。

## 分析前必须记录

1. 效应量类型与尺度，例如 log RR、log OR、Fisher z、标准化均差；不要混合原始比值与对数比值。
2. 效应方向，例如正值究竟代表获益还是伤害。
3. 统一的估计目标、结局定义、时间点和对照条件。
4. 每行对应独立研究还是同一研究的多个效应量；后者不能直接交给基础脚本。
5. 方差的推导方法，以及是否包含设计效应、聚类或配对结构。

## 不适合基础脚本的输入

- 同一研究多个结局、时间点、亚组或治疗臂且未处理相关性；
- 多层、聚类、重复测量、稳健方差估计；
- 诊断准确性、剂量反应、网络元分析、IPD 元分析；
- 需要 Hartung-Knapp 之外的复杂小样本修正；
- 需要从原始 2×2 表、均值/标准差或生存曲线推导效应量。

遇到这些情况，应先建立适当的数据结构和模型，不能通过删除行或任选一个效应量来“修复”。
