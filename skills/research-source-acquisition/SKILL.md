# 科研数据与论文获取

把“发现来源”推进到可审计的全文或数据文件，或准确停在必须由用户完成的身份、协议、伦理、机构或付费步骤。不要把数据库名单、落地页、HTTP 200、题录或文件片段误报成已经取得可用内容。

## 授权维度必须分开

以下动作互不自动授权：

1. 发现与核验来源；
2. 注册、申请、接受协议或付费；
3. 下载并保存文件；
4. 打开、解压或读取文件内容；
5. 清洗、分析、上传、共享或用于 AI。

用户可以只授权“代为下载”。在 `download_only` 模式下，只把文件保存到用户指定或隔离目录，核验路径、大小、文件类型和 SHA-256；不要打开、解压、抽样读取、索引或分析内容。若平台协议禁止云端 AI 读取数据，下载权限仍可与读取权限分开处理。

公开发布版不携带任何人的持续授权。只有当前用户在当前任务中明确同时授权下载后的读取或分析，且适用许可证、数据使用协议和平台规则明确允许相应 AI 处理时，才可继续打开内容；否则停在下载验收与元数据登记。若许可不明、规则冲突、限制云端/生成式 AI，或用户指定 `download_only`，不得推定读取权限。

## 模式

- **公开获取**：无需身份即可检索、下载并核验论文或数据。
- **协作获取**：需要用户本人登录、输入验证码、提交身份材料、接受协议、使用机构权限或付款；Codex负责定位、准备、在用户授权后操作已登录会话及下载验收。
- **仅代下载**：取得文件但不读取内容，适合受数据协议限制的材料。
- **可用性审计**：测试来源能否返回题录、全文、完整文件或结构化数值，不下载无关大文件。

## 路由

- 只发现题录、DOI、PMID、arXiv ID：使用 `academic-literature-search`。
- 取得并核验论文全文：读取 [references/source-matrix.md](references/source-matrix.md) 的“论文全文”部分，并按 [references/acquisition-protocol.md](references/acquisition-protocol.md) 验收。
- 获取研究数据：读取来源矩阵中对应学科部分；若来源需要账号或协议，再读取 [references/access-and-policy.md](references/access-and-policy.md)。
- Dryad 公开文件：调用 `dryad-data-fetcher`，不要复制其 Anubis 自动化。
- 国家统计局“国家数据”：使用 `scripts/Get-NbsPublicData.ps1`。
- 普通网页、JS 页面或浏览器后备：调用 `web-tool-router`；登录敏感页面必须复用其认证浏览器协议。
- PDF 文件身份、页数和视觉检查：取得文件后使用 `pdf`；需要深读时再使用 `scientific-paper-reading`。
- 系统综述的数据库覆盖和检索协议：交给 `literature-review`；本 Skill 只负责具体来源的获取与证据登记。

## 执行契约

本 Skill 只允许通过 `$research-source-acquisition` 显式调用。开始前读取 [权限、安全与成本边界](references/security-and-permissions.md)，把公开发现、文件下载、账号协作、申请/联系和付款分别授权；一次授权不能跨层级复用。

1. 从研究问题或标识符确定所需对象、变量、总体、时间、空间、粒度和可接受版本。未来需求未知时，不要求用户预先注册所有数据库；按具体任务启用来源。
2. 搜索论文的数据可用性声明、补充材料、项目/数据集编号、作者或机构仓库、官方 API 和合法开放版本。详细线索见来源矩阵。
3. 为每一项维护证据状态：`已发现`、`已取得题录`、`已取得摘要`、`已取得结构化全文`、`已取得完整文件`、`已取得可用数据`、`仅取得文件片段`、`需注册`、`需申请`、`需机构权限`、`需付费`、`当前失败`。
4. 优先官方 API、稳定下载地址和可复现的批量协议；具体协议选择见获取协议。只有公开站点需要 JavaScript 或页面交互时才用浏览器。限制重试，保留真实失败。
5. 下载后核验最终 URL、状态码、Content-Type、字节数、文件头、预期题名/DOI/数据集标识和 SHA-256。论文 PDF 还要核对页数、标题和版本；数据压缩包必须确认是完整文件而非 HTML、登录页或 Range 片段。
6. 默认不覆盖。相同内容可复用；同名不同内容用版本或短哈希区分。保留原始文件、代码本、许可证、检索/下载时间和来源 URL。
7. 遇到身份、密码、验证码、法律协议、伦理承诺、机构签署或付费时停下让用户本人处理。用户完成并明确授权下载后，可以复用其已登录会话，但不要读取、导出或记录凭据。
8. 取得数据后检查许可证、数据使用协议和平台规则。只有用户在当前任务中明确授权读取/分析且规则允许时才继续；若授权或规则任一不明，则停在下载与元数据登记。取得成功本身不能推导出分析许可。

## 已验证事实与漂移

[references/source-matrix.md](references/source-matrix.md) 记录了截至 2026-10-23 的实测来源和候选来源。它是路由经验，不是永久可用保证；实际任务必须重测当前端点、访问条件和具体记录。不要用一次成功概括整个平台。

## 交付

至少报告：对象、来源、访问日期、稳定标识符、证据状态、实际保存路径、大小、SHA-256、版本/许可证、是否允许 Codex读取、失败与后备路径。若只完成发现、申请或文件片段验证，明确写出尚未取得完整内容。
