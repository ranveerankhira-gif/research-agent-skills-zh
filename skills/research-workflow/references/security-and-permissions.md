# 安全与权限

本 Skill 负责协调，不因“全流程”三个字获得对全部文件、工具、账号或外部系统的权限。每个阶段沿用用户当前请求的范围，并服从被路由专用 Skill 的更严格限制。

## 材料与文件

- 只读取用户明确指定的论文、数据、代码和项目文件；不扫描相邻目录、邮箱、浏览器、文献库、云盘或其他研究项目。
- 参与者级数据、未公开稿件、审稿意见、基金材料和受限文献不得上传到第三方服务。
- 证据台账、提纲、草稿、分析计划或报告写入前确认目标路径；默认创建新文件，不覆盖原材料、原始数据、代码或既有结果。

## 阶段授权

- 联网检索只访问当前阶段需要的公开来源，并记录检索日期与边界；登录、验证码、付费墙、订阅和受控访问不在默认范围内。
- “制定分析计划”不等于授权运行代码；“准备投稿材料”不等于授权登录或提交；“规划数据共享”不等于授权上传或公开。
- 安装依赖、运行代码、修改数据、使用云算力、联系参与者、创建外部项目、投稿和付费操作，必须由用户在对应阶段另行明确要求，并由适用专用 Skill 处理。

## 路由与目标控制

只启用当前阶段确实需要的专用 Skill，不一次性叠加整套科研 Skill。若专用 Skill 的固定流程、平台或输出结构与用户目标冲突，以用户目标为准；先说明冲突，不擅自改换研究问题、方法、期刊、平台或成功标准。
