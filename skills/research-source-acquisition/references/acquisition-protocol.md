# 获取与验收协议

## 一、从哪里寻找

不要只搜数据库首页。依次检查：

- 论文正文的 Data Availability Statement 和 Supplementary Materials；
- DOI、PMID、PMCID、arXiv ID、NCT、GEO/SRA/ENA、PDB、ICPSR 等稳定标识符；
- 作者主页、实验室、机构知识库、基金项目页和数据论文；
- Zenodo、Dryad、Figshare、OSF、Dataverse、Mendeley Data、GitHub/GitLab Releases；
- 学位论文及其附件、临床试验注册、预注册、政府报告附件、行业协会报表、国际组织 API；
- 后续论文引用的数据集新版本、机构镜像和网页存档。

原始数据不可得时，可以合法提取论文表格、补充表、森林图、散点图、生存曲线或公开报告，但必须标记为“原文直接提取”“图像数字化估计”“公开数据重算”“多来源拼接”或“模型推算”，不得冒充作者原始数据。

## 二、接口与传输路线

根据来源实际提供的能力选择 REST、GraphQL、SPARQL、OAI-PMH、SDMX、CKAN、Socrata、Dataverse API、FTP/SFTP、S3/对象存储、THREDDS、ERDDAP、Git/Git LFS 或 GitHub/GitLab Releases。协议名称只说明候选路线；必须用具体记录或文件实测，不能因为平台声称支持某协议就报告为已取得。

- 优先稳定标识符、官方批量接口和可复现请求；网页点击是后备。
- 大文件先取得清单、大小、校验值和许可，避免无关下载。
- 需要专用客户端或命令行工具时，先核对官方来源、版本、安装位置和权限，不自动安装未知工具。

## 三、证据状态

| 状态 | 最低证据 |
|---|---|
| 已发现 | 有官方或可追溯记录，未证明内容可取 |
| 已取得题录 | 官方题录接口实际返回记录 |
| 已取得摘要 | 响应实际包含摘要 |
| 已取得结构化全文 | XML/HTML/BioC 等包含正文段落并核对论文身份 |
| 已取得完整文件 | 完整字节、正确类型/文件头、大小与哈希已核验 |
| 已取得可用数据 | 完整文件或结构化值可解析，口径/变量/许可证已登记 |
| 仅取得文件片段 | HTTP 206、Range 片段或截断响应；不能称完整数据 |
| 需注册/申请/机构权限/付费 | 已核对官方条件，但未获授权或未下载 |
| 当前失败 | 本轮端点超时、限流、拦截、失效或返回错误内容 |

“HTTP 200”不是证据状态。PDF 名称可能对应 HTML Cookie/Cloudflare 页面，ZIP/CSV 链接也可能返回登录页。

## 四、文件验收

记录并检查：

1. 请求来源、检索式/标识符、访问时间和最终 URL；
2. HTTP 状态、Content-Type、Content-Length 或实际字节数；
3. 文件头/魔数、归档可读性、页数或表头；
4. 题名、DOI、作者、数据集 DOI/accession、版本与许可证；
5. SHA-256；
6. 是否完整、是否为派生/预印本/作者手稿、是否允许读取和再分发。

对 PDF，至少核对 `%PDF`、题名/DOI和页数。对 CSV/Excel/ZIP，核对实际格式，不因扩展名判定。对 NetCDF/GeoTIFF/序列文件使用相应只读检查器。

## 五、保存与碰撞

- 保留原始文件，不在原文件上清洗。
- 优先保存到用户指定目录；大型或长期科研数据默认放 D 盘独立目录。
- 同名目标已存在时先计算哈希：相同则复用，不同则用版本/短哈希新建；不得静默覆盖。
- 临时下载使用随机 `.partial` 文件，成功验收后再原子移动；失败时只清理本流程创建的临时文件。
- 保存来源、下载时间、标识符、许可证、大小和哈希；不要把 Cookie、Token 或认证头写入日志。

## 六、登录与外部动作

只读发现和公开下载可直接进行。以下动作需要用户本人或新鲜授权：

- 注册账号、提供身份/机构信息；
- 输入密码、验证码或 MFA；
- 接受数据使用协议、伦理与法律承诺；
- 提交申请、联系作者/数据管理人、付费；
- 使用机构订阅或安全环境；
- 上传、共享或公开数据。

用户已明确授权下载且已登录时，可协助选择和下载，但不要请求其在聊天中粘贴密码、API Key 或 Cookie。

## 七、失败与后备

- DNS、超时、连接重置、5xx：最多重试一次。
- 429：按官方说明有限退避一次，然后转合法后备，不无限撞接口。
- 401/403：先区分错误端点、JS 验证、登录、WAF、授权和付费墙；不要把所有 403 都叫“需要登录”。
- 出版商受限：查 PMC/Europe PMC、arXiv/bioRxiv/medRxiv、机构仓储、作者手稿、CORE/OpenAlex/Unpaywall 线索；ResearchGate只作为作者上传版本的发现线索，仍核验版本与合法访问，不使用盗版来源。
- 页面成功但结果不相关：用 DOI、精确题名和最终文件身份二次核验。
