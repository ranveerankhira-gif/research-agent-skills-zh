# 问卷与量表研究

支持科研问卷从构念定义到试测、实施和测量验证的全过程，但不把漂亮题目、较高 Alpha 或良好拟合指标误当成量表有效的充分证据。本 Skill 只允许通过 `$survey-and-psychometrics` 显式调用。

## 路由

- **问卷设计/审计**：读取 [references/questionnaire-design.md](references/questionnaire-design.md)。
- **量表开发与验证**：读取 [references/psychometric-validation.md](references/psychometric-validation.md)。
- 同一任务同时包含两者时再读取两份；不要默认把普通调查表升级成心理量表项目。

先明确研究构念、目标人群、用途、语言、施测模式、决策后果、已有量表和样本设计。若用户给出既有量表，先确认版权、许可和改编边界；公开看到题项不代表允许复制、翻译或重新发布。

## 不可混淆的证据

1. **信度不等于效度**；内部一致性高不能证明测量了目标构念。
2. Cronbach's alpha 依赖模型假设、题目数量和样本；不得只报 Alpha 就宣布量表可靠。
3. 探索性因子分析与验证性因子分析承担不同任务。不得在同一数据上反复试配后仍把结果当作独立验证。
4. 拟合指数没有脱离模型、样本和理论的万能阈值；报告指标、判据、修订和数据驱动决策。
5. 测量不变性应围绕实际比较目标解释。统计不变性、实质可比性和公平性不是同义词。
6. 翻译与回译只是跨文化适配的一部分；还需目标人群认知访谈、文化等值和测量证据。

## 权限与数据边界

- 处理真实问卷、量表或参与者数据前，读取 [references/security-and-permissions.md](references/security-and-permissions.md)。方案咨询不需要读取参与者级材料。
- 不自动创建或发布在线问卷、发送邀请、购买样本、联系参与者、登录 Qualtrics/问卷星/REDCap，或上传未公开题项和参与者数据。
- 不把姓名、联系方式、设备标识、健康/教育/财务信息发送到外部服务。需要真实数据分析时，先确认去标识化、变量字典和授权范围。
- 读取文件前确认授权范围，不扫描相邻目录。生成题项表、数据字典、分析代码或报告时先确认目标路径，默认创建新文件，不覆盖原问卷、原始数据或既有结果。
- 用户要求核对当前规范、版权或平台要求时，只访问公开官方来源；不登录平台，不上传本地材料，并记录来源与核验日期。
- 不虚构试测样本、专家评审、认知访谈、因子载荷、信效度、响应率或不变性结果。

## 与其他 Skill 的边界

- 一般统计建模、功效分析和结果报告使用 `statistical-analysis`；本 Skill 负责测量模型、题项与调查方法含义。
- 实验分配、随机化和处理结构使用 `experimental-design`。
- 涉及参与者同意、敏感信息或伦理审批时使用 `research-ethics-consent`；本 Skill 不替代伦理审查。

## 交付

根据任务提供构念—题项蓝图、问题与选项、跳转逻辑、认知访谈方案、抽样/联系方案、问卷审计表、测量模型计划、分析代码建议、证据矩阵或结果解释。明确区分计划、模拟示例和真实数据结果；说明尚未验证、仅初步证据或适用人群受限之处。
